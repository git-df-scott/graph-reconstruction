# SOL_5 — The deletion-fragile parity hole

The grander candidate mechanism was a global parity obstruction that becomes
removable after **every** single vertex deletion.  That would give the exact
logical form of a Kelly–Ulam counterexample: nonisomorphic intact parents and
isomorphic full card multisets.

The simplest version is now closed by a theorem.  If a binary CFI code admits
an odd translation after deleting each of its words, the code has only one
word.  Allowing arbitrary coordinate relabelings does not rescue it through
dimension four: an exhaustive classification of 65,774 nontrivial code
subsets across dimensions 2–4 found zero complete deletion-release codes.

The failure points to a genuinely different symmetry source.  I constructed
the exceptional outer action of `S6` exactly from its 15 duads, 15 synthemes,
and six totals.  Its ordinary point stabilizer and exotic total stabilizer
are both `S5`, but they are nonconjugate: one has point orbits `1+5`, the other
is transitive.  Every ordinary/exotic stabilizer intersection has order 20.

That is the new hole: build a graph on the natural 15-element
duad/syntheme carrier so every deleted card may use one of those local
ordinary/exotic intersections, while any parent isomorphism would have to
realize the outer automorphism by conjugation.  No permutation of six points
can do that.

This is not yet a counterexample.  It is a legal-order, exact group-theoretic
primitive that evades both the Goldilocks rescue-regeneration obstruction and
the covering-space gauge obstruction.  The next computation is a constrained
orbital/double-coset search on this fixed `S6` geometry, followed—only if a
zero-globalizer system appears—by binary realization and hostile full-deck
verification.
