# Exact local-map construction

Let the two parent vertex sets be disjoint labelled copies
`X={x_0,...,x_(n-1)}` and `Y={y_0,...,y_(n-1)}`.  The current normalized
search matches deletion `x_i` with deletion `y_i`.  For each `i`, it chooses
a bijection

`sigma_i : X - {x_i} -> Y - {y_i}`.

Normalization is only a choice of the deck-card matching: an arbitrary
bijection between deleted vertices can be absorbed by relabelling `Y`.

## Three distinct layers

### 1. Local permutation system

The input is the tuple `(sigma_0,...,sigma_(n-1))`.  No compatibility on the
overlaps of two deleted cards is assumed.  Failure of every `sigma_i` to
extend to a parent permutation says nothing by itself about reconstruction.

### 2. Edge-class constraint system

Introduce Boolean variables `A_{uv}` and `B_{rs}` for unordered pairs on the
two parent sets.  For every `i` and every `u,v != i`, impose

`A_{uv} = B_{sigma_i(u),sigma_i(v)}`.

The equivalence relation generated by these equations partitions the
`2*binom(n,2)` edge positions into classes `C`.  Equivalently, each edge of
the two complete parent graphs receives its class label.  These labels are
names of shared variables, not graph edge colors that may be freely renamed.

A parent permutation `tau:X->Y` is an **exact-label globalizer** when

`class(A_{uv}) = class(B_{tau(u),tau(v)})`

for every unordered pair `{u,v}`.  Such a `tau` maps the two class-labelled
complete graphs and therefore works for every binary realization.

More generally, every `tau` produces a set of required equalities

`R_tau = {(class(A_{uv}), class(B_{tau(u),tau(v)}))}`.

For a particular binary assignment `c:C->{0,1}`, `tau` is a parent graph
isomorphism exactly when `c(a)=c(b)` for all `(a,b)` in `R_tau`.  Thus a
class-permuting structural symmetry need not survive a particular binary
assignment.  An exact-label globalizer has only tautological pairs and cannot
be broken by any assignment.

### 3. Binary graph realization

Choose `c:C->{0,1}` and put edge `{u,v}` in `G_c` precisely when
`c(class(A_{uv}))=1`; define `H_c` analogously.  Every generating equation
then gives

`G_c-{x_i} ~= H_c-{y_i}` via `sigma_i`.

Since the deleted vertices are matched bijectively for every `i`, these `n`
explicit isomorphisms prove equality of the complete vertex decks with
multiplicity.  This implication does not depend on hashes or canonical forms.

The realization is a counterexample exactly if no vertex permutation `tau`
satisfies all of its binary equalities.  Equivalently, the assignment must
make at least one pair in every `R_tau` unequal.  The finite solver in
`local_gluing_search.py` checks this condition directly and an apparent hit
must still pass the independent exact deck and graph-isomorphism backends.

## Easy implications

1. The generating equations imply all prescribed card isomorphisms, hence
   exact deck equality with multiplicity.
2. An exact-label globalizer implies `G_c ~= H_c` for every assignment `c`.
3. Absence of an exact-label globalizer is necessary but not sufficient for a
   counterexample: the equality condition of some other `tau` may hold after
   classes are assigned the same bit.
4. A binary assignment defeating every `R_tau` produces nonisomorphic parents
   inside this construction.  Together with item 1, it is a genuine GRC
   counterexample and triggers hostile independent verification.
