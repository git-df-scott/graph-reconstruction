## Primitive rescue structure

The frozen three-class primitive has exact G-to-H rescuers

```text
a = (0,2,1,3,4,5) = (1 2)
b = (4,1,2,5,0,3) = (0 4)(3 5).
```

They commute and generate

`K={1,a,b,ab} ~= C2 x C2`.

The three vertex orbits of `K` are `{1,2}`, `{0,4}`, and `{3,5}`.  The
centralizer of `K`, normalizer of `K`, and set-normalizer of `{a,b}` all have
order 16.  The equality follows structurally because `a`, `b`, and `ab` have
distinct cycle types, so a normalizer of `K` cannot permute the three
nonidentity elements.  The rescue set consequently has 45 conjugates.

On unordered pairs, `a` swaps the edge positions induced by `(1 2)` and `b`
acts through `(0 4)(3 5)`.  Both map the G-side class array

`[1,2,0,0,1,2,2,2,1,1,1,2,1,2,0]`

to the H-side class array

`[2,1,0,0,1,2,1,1,2,2,2,1,1,2,0]`

without renaming the shared class variables.  Hence both survive every binary
assignment.

## Exact coupling definition

For a twist `t in S6`, the second primitive is obtained by simultaneously
relabeling both parent copies, so its maps are `t sigma_i t^-1`, reindexed by
the deleted vertex.  The coupled partition is generated by all equations from
both complete map families.  Either family alone certifies all six card
isomorphisms, so every binary coupled realization still has exact deck
equality with multiplicity.

The side-reversed orientation, obtained by replacing every map by its inverse
before twisting, was checked separately.

## Double-coset obstruction

The rescue-set normalizer gives eight double cosets in `N\S6/N`, of sizes

`16, 32, 128, 256, 128, 64, 64, 32`.

The first retains both old rescuers; the second retains one; the remaining
six, totaling 672 twists per orientation, make the two old rescue sets
disjoint.

Every one of those 672 apparently favorable twists collapses the coupled
edge relation to one equivalence class.  It therefore creates all 720 parent
permutations as exact-label globalizers.  This was checked directly for every
twist, rather than inferred only from rescue-set intersection or a hash.

This is why the rescue survives: adding the incompatible second equation
family merges edge variables asymmetrically until all distinctions vanish.
The frustration operation destroys the information needed to remember the
twist.

## Theorem extracted

**Two-copy same-carrier theorem (computationally exhaustive).**  Couple the
frozen order-six primitive with any simultaneous relabeling of itself or its
side reversal, imposing both complete card-map families on the same six
parent vertices.  The resulting edge-class system has an exact-label
globalizer.  Consequently no binary assignment produces nonisomorphic
parents.

This theorem covers exactly 1,440 specified couplings.  It does not cover
larger carriers, partial-overlap embeddings, or couplings with a different
primitive, and it is not GRC.

### Minimal partial overlap

The justified next carrier was also decided exactly.  On seven vertices, take
two six-vertex primitive blocks sharing five vertices.  For deletion inside a
block, extend the corresponding primitive map while fixing the outside
vertex.  For deletion of that outside vertex, use either of the block's two
rescuers.  This produces a complete legitimate seven-card family for each
block.

The exact domain contains:

- 720 embeddings of the second block;
- two side orientations;
- two outside-deletion rescuers for each block;
- 5,760 coupled systems total.

Each single promoted block has four edge classes.  Every coupled pair has
exactly one.  Therefore all 5,760 systems have all `7! = 5,040` exact-label
globalizers and no assignment-specific separator.

This gives a second computational theorem: the minimal five-vertex-overlap
coupling always becomes indiscrete.  The cross-edge repair equations supplied
by the two different outside vertices connect the four components retained by
each individual lift.

Reproduce with:

```bash
python3 scripts/analyze_partial_overlap_couplings.py
```

The next viable design must change the extension rule or use a different
primitive whose outside-deletion repair does not join every edge-class
component.  Adding a third copy of this primitive cannot recover distinctions
once the first two copies have collapsed them.
