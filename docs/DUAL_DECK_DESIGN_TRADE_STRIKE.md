# Dual-deck design-trade strike

## Binding verdict

```text
GRC CE: NO
```

No pair of nonisomorphic ordinary finite simple graphs with the same complete
vertex deck was found.

## Source recovered exactly

Kocay's explicit nonreconstructible 3-uniform pair `X^n,Y^n` was recovered
from the published polynomial construction.  The smallest pair (`n=3`) has
9 points and 28 blocks on each side.  Its complete block lists are stored in
`data/kocay_n3_pair.json`; the recursive construction is implemented for all
`n >= 3` in `scripts/dual_deck_trade_strike.py`.

Primary source: W. L. Kocay, *A family of nonreconstructible hypergraphs*,
JCTB 42 (1987), 46--63,
<https://doi.org/10.1016/0095-8956(87)90062-1>.  The explicit modern
restatement used for transcription is Cooper--Okur,
<https://arxiv.org/abs/2312.16152>.

The exact point-permutation checker independently verifies that the parents
are nonisomorphic and that their standard induced-hypergraph point decks are
equal.  At `n=3`, each deck has card-type multiplicities `1,2,2,2,2`.

## The category-transfer obstruction

The source audit exposed a crucial distinction:

```text
induced hypergraph deletion:
    delete point p AND discard every block containing p

incidence-matrix row deletion:
    delete point p BUT retain every block column
```

In the second operation, an incident triple becomes a two-point column; two
columns that become equal remain distinct block objects.  Kocay's theorem is
about the first operation.  The Blue-LED incidence target needs the second.

After correcting for this distinction, the `n=3` pair is not close to a row
deck collision: each side has five incidence-row card types and **zero card
types match across the pair**.  Its block decks also fail: only two card types
match between 14 types on `X^3` and 16 on `Y^3`.

The `n=4` published lift has 17 points and 200 blocks per side.  It repeats the
same obstruction:

| test | exact result |
|---|---:|
| induced point decks | equal |
| incidence row types | 9 vs. 9; 0 common |
| block-card types | 100 vs. 104; 4 common |
| complement incidence row types | 9 vs. 9; 0 common |

Thus the lift amplifies rather than cancels the missing equations.

## Exact trade algebra

At `n=3`, the discrepancy at the special point is generated by the six pairs
of four residue classes modulo four.  Toggling the complete bipartite block
module on each class pair gives a sharply bounded six-dimensional space of
`2^6 = 64` labeled hypergraphs around Kocay's fixed 20-block core.

This entire source-derived space was classified exactly:

| quantity | count |
|---|---:|
| labeled members | 64 |
| parent isomorphism types | 40 |
| induced point-deck classes | 37 |
| nonisomorphic induced point-deck pairs | 6 |
| incidence row-deck classes | 40 |
| nonisomorphic incidence row-deck pairs | 0 |
| block-deck classes | 40 |
| nonisomorphic block-deck pairs | 0 |
| dual-deck classes | 40 |
| nonisomorphic dual-deck pairs | 0 |

### Finite-family theorem

> In the complete six-module residue-pair trade space around Kocay's
> `Gamma_3` core, both the incidence row deck and the block deck separately
> determine the parent up to two-sorted incidence isomorphism.

This is computationally exhaustive for the stated 64-member family.  Every
isomorphism decision is exact; invariants only select candidate buckets.

## Independent verification

The primary implementation searches unrestricted point bijections using
degree and codegree refinement, then compares the full transported block
multiset at every successful leaf.  Repeated shrunken columns are retained.

The regression suite independently converts every incidence structure into
an ordinary split graph: point vertices are independent, block vertices form
a clique, and incidence gives cross edges.  The ordinary graph backtracker
confirms parent nonisomorphism and confirms that no `X^3` incidence-row card
is isomorphic to any `Y^3` incidence-row card.

## Strongest obstruction and next address

Known induced-hypergraph reconstruction counterexamples are not automatically
source objects for incidence bidecks.  Any future import must provide
**trace hypomorphy**—equality after deleting a point from every block while
retaining the full block multiset—not merely induced hypomorphy.

The next credible address is therefore an explicit nonreconstructible
set-system under trace deletion (also called a vertex-trace or contraction
deck in some conventions), or a paired trade construction whose discarded
incident blocks are reintroduced in a deletion-compatible way.  Further
scaling of Kocay's lift or its six residue modules is not justified.
